# CampusConnect 2.0 测试版（Windows Beta 1）

版本：**2.0.0-beta.1**。本次仅更新 Windows，macOS 保持 1.5.2。本版本作为 GitHub **Pre-release** 发布，1.5.2 仍为稳定版。

## 更新内容

- 明确增加「Wi-Fi 无线网络 / 有线网络（以太网）」选择，修正有线状态下仍显示 Wi-Fi 的图标、名称与提示。修改后保存即用于实际连接，旧版 Wi-Fi 名称留空的配置继续可用。
- 有线模式可选网页认证、PPPoE 宽带拨号、802.1X 系统认证与学校专用客户端。
- PPPoE 使用 Windows 中已创建并保存凭据的宽带连接；实际网卡由该系统宽带配置决定。
- 802.1X 复用系统配置，对指定以太网接口请求重新认证。需按学校要求设置 EAP、证书及凭据并启用 Wired AutoConfig，运行权限由 Windows 管理。
- 学校客户端模式启动用户选择的已安装客户端，已运行时不重复启动；客户端内登录、验证码与学校私有协议由该客户端处理。
- 认证前检测物理以太网不再要求已经获得 IP，允许先发起拨号或 802.1X。
- 网页认证自动勾选可识别的必选框与登录协议项，触发网页原有事件；已勾选不重复操作。勾选被拒绝或需要人工阅读确认时暂停提交并提示处理，不改变记住密码、广告订阅等可选项。

## 使用

1. 安装 Windows x64 包，进入「校园网设置」。
2. 选择 Wi-Fi 或有线网络；有线模式选择学校实际使用的认证方式。
3. 网页认证填写认证地址、账号和密码；没有服务选项时留空。PPPoE / 802.1X 先完成 Windows 中的配置，学校客户端先选择已安装程序。
4. 保存设置后点击「立即连接」；需要后台持续检查时开启自动连接。

## 验证范围

Windows 核心 2115 项、网页必选框/协议框 36 项、连接方式选择与保存恢复、桌面交互、80 项后台恢复、18 项基础认证、ePortal、提前初始化及性能回归通过。Windows x64 自包含构建、NSIS 安装包生成、文件清单与发布校验完成。

尚未完成本测试版的 Windows 原生安装/卸载、真实校园 PPPoE / 802.1X、学校客户端运行、学校实际协议框及网线拔插验证。不得将系统命令返回或百度 ping 成功当作对应学校认证已完成的证明。Windows 浏览器和 ping 使用系统路由，多网卡 / VPN 环境需确认学校地址可达。
