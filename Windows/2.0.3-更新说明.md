# Windows 2.0.3 修订正式版

## 修复与新增

- 修复运营商单选框旁用 `font` 标签显示名称时，无法识别“中国移动”等选项的问题。
- 支持单选框与文字之间的空白、换行和 HTML 注释。按设置中的完整名称匹配，不依赖易变化的本地化编号。
- 使用学校网页原有点击事件；确认选中后再提交登录，避免重复点击。继续保留 2.0.2 的动态下拉菜单、顶部单选项和自定义服务名称支持。
- 左下角感叹号新增提示：“如果使用正常，也欢迎关注我的抖音，并发送你的大学名称，帮助更多小伙伴使用小助手。”现有问题反馈方式保留。
- 支持学校名单新增 **南通大学**。

## 使用方法

退出系统托盘中的旧程序，再运行 2.0.3 安装包。在“校园网设置 → 运营商 / 服务选项”填写网页上的完整选项名称，保存后重新认证。例如使用中国移动时填写 `中国移动`。

## 支持学校

河南工业职业技术大学、郑州信息工程职业学院、无锡职业技术大学、天津石油职业技术学院、华东交通大学、南通大学。其他学校也欢迎下载测试并反馈。

## 验证范围

将提供的 `span`、`input[name="network"][value="@cmcc"]` 和 `font` 片段加入回归。相同片段上，2.0.2 返回 `missing-service` 并保留默认选项；修复后选中 `@cmcc`，触发 `click/input/change`，再提交一次登录。只填写和重复检查模式也有覆盖。

本地检查包括 Windows 核心、运营商与动态菜单、协议勾选、初始化、界面反馈入口及最小窗口布局；发布前另对实际上传安装包执行 Windows 安装、启动、修复、升级和卸载检查。真实学校页面完整脚本与校园网络认证仍需在对应网络验证。
