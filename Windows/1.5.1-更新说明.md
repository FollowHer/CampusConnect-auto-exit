# Windows 1.5.1 更新说明

针对长时间后台运行后重新打开窗口出现白屏的问题：

- 从托盘打开、从最小化恢复时自动刷新界面；切换到其他程序超过一分钟后返回也会刷新。
- 保留当前页面、未保存的账号设置及高级设置展开状态；恢复草稿仅在内存中保存。
- 内置界面进程退出或卡死时自动重载，失败后重建浏览器控件；仍失败时显示重试按钮。托盘新增“刷新界面”。
- 正常界面刷新不重载学校认证网页，不重复启动自动连接；保留 1.5.0 的服务选项、登录结果校验及百度 ping 检测。

安装：先在 Windows 右下角托盘退出旧版，再运行 CampusConnect-Windows-x64-1.5.1-Setup.exe，选择原安装目录覆盖升级。已有配置保留。

本次仅更新 Windows。macOS 保持 1.5.0，Linux 未修改。

验证：Windows x64 自包含 ReadyToRun 编译通过；2068 项核心检查、80 项刷新恢复检查、18 项基础认证脚本检查，以及界面、ePortal、提前初始化、性能和安装清单回归通过。安装包 PE 版本/架构、NSIS CRC32 和 SHA-256 校验通过。

验证边界：当前测试环境为 macOS；未启动 Windows 虚拟机、未执行安装或卸载，未在 Windows 实机验证长时间后台、睡眠唤醒或 WebView2 进程崩溃恢复。以上浏览器回归不替代这些实机检查。
