# Windows 2.0.2：顶部运营商单选项

在 2.0.1 下拉菜单修复的基础上，新增顶部横向单选项支持，例如「校园网 / 中国移动 / 中国电信 / 中国联通」。

- 支持放在登录表单上方或表单外的标准单选框。
- 支持标签包裹、独立标签、紧邻文字和通过标签显示的隐藏单选框，以及可识别的自定义单选项。
- 按“运营商 / 服务选项”中保存的完整名称匹配，支持学校自定义名称。
- 调用网页原有点击和更改处理，让学校页面更新运营商参数；确认选中后才登录。
- 已选中时不重复点击。异步选中时等待；找不到、禁用、名称不唯一、选择被拒绝时不提交登录。
- 设置留空时保留网页的默认单选项。原有下拉框和动态菜单处理继续保留。

## 使用方法

1. 退出旧版程序，再安装 Windows 2.0.2 x64。
2. 在“校园网设置 → 运营商 / 服务选项”填写网页显示的完整名称。例如使用中国移动时填 `中国移动`，使用校园网选项时填 `校园网`。
3. 保存设置后重新认证。其他选项按同样方法填写。

## 验证范围

Chromium 模拟页面覆盖顶部单选项、校园网和三大运营商、自定义名称、隐藏单选框、网页更改事件、异步选中、表单隔离、禁用项、同名歧义、选择被拒绝及提交顺序，同时回归原有标准下拉框和动态菜单。

本地验证通过：Windows 核心测试 2115 项、脚本检查 18 项、协议勾选检查 36 项，以及运营商选择、页面初始化和界面回归。Windows x64 自包含单文件交叉编译通过，已核对编译后认证脚本、界面资源与当前源文件一致，程序集版本为 2.0.2.0。安装器文件清单与个人数据排除检查通过。

仅修改 Windows；Windows 启动项注册表集成检查在 macOS 上跳过。真实学校认证页面及 Windows 原生安装运行仍需实测。
