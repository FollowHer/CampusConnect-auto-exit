# Windows 2.0.1：运营商选择修复

修复账号密码已经填写，运营商仍停在“选择运营商”的情况。

- 标准下拉框即使放在账号密码表单外，也能选择保存的完整选项名称，并触发网页的输入和更改事件。
- 对可识别的动态菜单，先点击展开，再等待列表出现并选择；选中后才点击登录。
- 名称按设置匹配，不限制为移动、联通、电信；支持学校自定义的服务名称。
- 菜单选项或选中结果延迟更新时等待，不反复展开和关闭菜单。原来选中了其他服务时，可以切换到设置中的服务。
- 没有配置服务名称而网页仍显示选择提示时，提示补充设置。找不到、同名项不唯一、选项禁用或网页拒绝选择时，不提交登录。

## 使用方法

1. 退出正在运行的程序，再安装 Windows 2.0.1。
2. 在「校园网设置 → 运营商 / 服务选项」填写网页显示的完整名称。使用中国移动时填 `中国移动`。
3. 保存设置，重新认证。以后更换服务，只需修改此名称并保存。

网页没有运营商或服务选项时留空。原有账号密码和网络设置继续使用。
