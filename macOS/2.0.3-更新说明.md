# macOS 2.0.3 修订正式版

同步 Windows 2.0.3 的运营商识别、选择与反馈提示，提供 Apple 芯片 / Intel 通用包，系统要求保持 macOS 14 或更新版本。

## 修复与新增

- 支持登录表单上方或表单外的运营商下拉框、顶部横向单选项，以及用 `font` 标签显示名称的选项。
- 动态运营商菜单先展开，等待选项出现，按保存的完整名称选择；确认选中后再登录。支持学校自定义名称。
- 对选项之间的空白、注释、延迟加载和异步确认进行处理。已选中时不重复点击；禁用、名称不唯一或选择失败时不提交登录。
- 设置项更新为“运营商 / 服务选项”，并对尚未配置运营商而网页显示选择提示的情况给出明确说明。
- 左下角感叹号新增：“如果使用正常，也欢迎关注我的抖音，并发送你的大学名称，帮助更多小伙伴使用小助手。”
- 支持学校名单包括河南工业职业技术大学、郑州信息工程职业学院、无锡职业技术大学、天津石油职业技术学院、华东交通大学和南通大学。

## 使用方法

退出菜单栏中的旧版应用，解压后将 `CampusConnect.app` 放入“应用程序”。在“校园网设置 → 运营商 / 服务选项”填写网页显示的完整名称，例如 `中国移动`，保存后重新认证。网页没有此选项时留空。

## 验证范围

本地执行核心和原生 WKWebView 检查，覆盖提供的 `network / @cmcc / font` 片段、选中前后事件、提交顺序、重复检查、表单外下拉框及延迟动态菜单。构建通用应用，并检查版本、两种 CPU 架构及本地临时签名。

应用沿用本地临时签名，未经过 Apple Developer ID 签名和公证。真实校园网络认证仍需在对应学校网络验证。
